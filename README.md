# Калькулятор чисел зубьев для механизма Джеймса

Этот проект представляет собой интерактивное веб-приложение на Streamlit для расчёта чисел зубьев в механизме Джеймса согласно заданным параметрам.

## Описание

Программа рассчитывает значения чисел зубьев (Z1, Z2, Z3) по заданным входным данным:

- Передаточное отношение \( i_{1H} \)
- Количество сателлитных колес \( K_2 \)
- Модуль зубьев \( m \)
- Минимальное число зубьев солнечной шестерни \( Z_{\min} \)

Реализованы проверки по необходимым условиям:

- \( Z_2 \) и \( Z_3 \) должны быть целыми числами
- \((Z_1 + Z_3)/K_2\) — целочисленное значение
- Условие соседства: \(\frac{Z_2 + 2}{Z_1 + Z_2} < \sin\left(\frac{180^\circ}{K_2}\right)\)
- Проверка передаточного отношения \( i_{1H} = 1 + \frac{Z_3}{Z_1} \)

Веб-интерфейс позволяет вводить параметры, запускать расчёт с прогресс-баром и отображать таблицу результатов с пометками о соответствии условиям.

## Использование

- Введите параметры:
  - Передаточное отношение (i_1H)
  - Число сателлитов (K_2)
  - Модуль зубьев (m)
  - Минимальное число зубьев (Z_min)
  - Максимум итераций
- Нажмите кнопку "Начать расчёт".
- Ознакомьтесь с таблицей результатов и выделенными подходящими решениями.
- При необходимости скачайте результаты в формате CSV.
